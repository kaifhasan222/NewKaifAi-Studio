# daily-short

1. Read `CLAUDE.md`, `PIPELINE.md`, `prompts/script-style-guide.md`, `prompts/hook-guide.md`, `prompts/script-fun-simple.md`.
2. Pick the next episode number from `episodes/` and copy `episodes/_template/` to `episodes/epNNN/`.
3. If a reference video is given, follow `prompts/reference-style-workflow.md` first: analyze it, write a style-card, get Kaif's OK. Copy the style only, never the content.
   If no topic is given, propose 3 topics (search the web for current tech news first) and wait for a choice.
   Before the script, ask which motion style from `prompts/motion-styles.md` (https://nafay3d.com). Wait for a name such as Pop Info. If Kaif says to pick whatever fits the video, choose one style, say which and why, then continue. Do not copy that site's prompt text, music, or voice.
4. Decide mode: Flow, or faceless (`prompts/faceless-mode.md`) when Flow credits are out or the topic suits animation/screen demo. Make it simple and fun per `prompts/script-fun-simple.md`: first write `Seedhi baat:` (the topic in one line a 10-year-old gets), pick one everyday desi analogy per concept (`Misaal:`), and plan 2-3 light jokes per 60s (`Hansi:`), never in the hook or a warning/step line and never bending a fact. Vary josh from 2 to 5, no 3 lines in a row at the same josh; before a joke `ruk 0.4`, the joke line `dheema, josh 2`. Hook first, per `prompts/hook-guide.md`: write 3 hooks of 3 different types, score them on the checklist, pick one, and record `Hook type:`, `Hook:`, `Hook options:`, `Hook text (overlay):`, `Hook visual (frame 1):` in `script.md`. First spoken line under 10 words and done within 2s, the real point in the first 3 words, no "aaj poora tareeka" intro in Scene 2, and not the same hook type as the previous 2 episodes. Add a rehook line at 40-50% and a last line that loops to the first. Ending: the last spoken line is a comment question about this topic asking the viewer's own view (answerable in 1-3 words); never speak "follow/like/subscribe", show those only as the end animation. Write `script.md` (Hinglish, 30-60s, hook in first 2s, one idea, comment-question ending) and `flow-prompts.md` using `prompts/flow-prompt-template.md`. Each `Voice:` line is only what gets spoken, in Devanagari, with a separate `Delivery:` in the form `tez|normal|dheema, josh 1-5, zor "शब्द", ruk <sec>` and an `Action:` (body language matched to josh) per `prompts/script-style-guide.md` and `prompts/voice-delivery.md`. Josh must rise and fall across the video: hook 5, middle 3-4, closing comment question 3. Put the scene's `Action:` and josh into the `@me` Flow prompt's Action. No filler reactions (`Aree`, `Achaa`, `Dekho`, `Matlab`, `Bas`). Do not stretch vowels. On-screen titles stay clean.
5. Generate clips in Google Flow if browser control is available; otherwise stop and ask Kaif to paste the prompts and put downloads in `raw-clips/` named `epNNN_01.mp4`, `epNNN_02.mp4`, ... Follow `.cursor/skills/google-flow/SKILL.md`: only the existing project **me**, `@me` is Kaif's voice, `@me_photo` is his avatar (face); every clip that shows Kaif uses both, plus the `CHARACTER:` line from `flow-prompts.md` copied word for word. Check each clip's face against `me_photo` and regenerate mismatches. If credits run out, switch to `newpub222@gmail.com` and use that account's **me** project. Do not type passwords. Faceless mode only after both accounts are out of credits.
5.5. Voice: ask Kaif to record `episodes/epNNN/voice_raw.mp3` using the Delivery card, run `tools/voice_report.py` on it, ask for re-takes of FIX lines, then `tools/polish_voice.py voice_raw.mp3 voice.mp3 --speed 1.05`. If Kaif wants the clone, run `tools/voice_indic.py episodes/epNNN/script.md --takes 2` with the `.venv-indic` Python (IndicF5; it picks each scene's best take by Whisper match and warns below 0.85; josh comes from the matching reference in `brand/refs/`, see `brand/refs/RECORD.md`), run `tools/voice_report.py` on the result, let Kaif pick takes with `--use scene=take`. If Kaif wants the Flow `@me` voice, put `Dialogue: @me says "<Voice line>" | Tone: ...` in each Flow prompt, then run `tools/flow_voice.py episodes/epNNN/episode.json` to build `voice.mp3` from the clips (lip-sync stays; no --speed or gap cutting). The clone reference is only Kaif's own recording (`brand/voice_ref.wav`), never anyone else's voice.
6. Make captions with `tools/make_captions.py`, rewrite to Roman Hinglish keeping timings.
7. Fill `episode.json` (clips, voice, music, sfx, captions, overlays) and run `tools/build_video.py`. Visuals per `prompts/visual-assets.md`: show an icon or image instead of text wherever a thing is named (the app's icon from `assets/graphics/icons/`, an original Gemini-made cartoon character from `assets/graphics/characters/` for people such as chacha), at least one per scene, and every image keeps moving (pop-in, then bob/wiggle/float; use the `sprite()` helper from `episodes/ep014/motion/mg.py`). No real person's photo except Kaif's own, no government emblems. Sound per `prompts/sound-design.md` (read it first): three SFX layers synced to the animation times (detail pops/clicks on every element, impact on hook/reveals, and one meme sound on the punch of every joke line), 50-70 SFX per 60s, never whoosh/glitch/typing/riser/faaah/shocked. Music `assets/music/lofi-upbeat-raspberrymusic.mp3` at volume 0.10 with its CC BY credit in the description (not the 24s `chill-tech-01` loop). Voice pauses must be cut (the clone tool does it; check no silence over 0.35s). Before delivery run the earshot noise check on each chosen take and on the final mix. Do not put music or SFX inside `voice.mp3`.
8. Run `tools/check_video.py`, look at the contact sheet, fix obvious issues, rebuild once.
8.5. Thumbnail: follow `prompts/thumbnail-guide.md`. Pick frames with `python3 tools/make_thumbnail.py --frames <clip>`, write `episodes/epNNN/thumb.json` (3 options A/B/C), run `python3 tools/make_thumbnail.py episodes/epNNN/thumb.json`, check the preview (3:4 grid box, Shorts UI zone), let Kaif choose.
9. Use the `youtube-seo-optimizer` skill (Mode E) for the SEO research and package, then write `episodes/epNNN/publish.md` (titles, description, tags, hashtags, pinned comment, Instagram caption, upload checklist) per `prompts/publishing-guide.md`, keywords from web search. Posting slots are 8:30 AM and 5:30 PM IST every day; write the date and slot in publish.md after checking which slots YouTube Studio already has scheduled. Channel "NEW KAIF AI" / @kaifhasan222, emojis per the guide's emoji rules, description and caption in copy-paste code blocks.
10. Report to Kaif: file path, the 3 hook options and which was used, what was assumed, what to check. Never post anything.
11. Do not git-add `episodes/epNNN/` or any video file. Photos and music/sfx may be committed. Push only to GitHub `kaifhasan222`.
