# ep001: Google Flow clips (Claude in Chrome ke liye)

Kaif ne Flow mein pehle se login kiya hai. Password ya login khud mat bharo.

## Rules
1. Sirf isi project mein kaam karo, jo abhi khula hai (Kaif ka **me** project). Naya project mat banao.
2. Settings: Video, model **Omni 1.2 Flash**, **x1** output, **9:16**, 8 sec. Har clip ke baad settings check karo.
3. Har prompt ke baad Flow "confirm" maangega. Credits dikhao, aur clip shuru karne se pehle Kaif se haan lo.
4. Prompt box mein `@me` aur `@me_photo` likhte waqt Flow ka chip/tag chuno (character). `@me` = Kaif ki awaaz, `@me_photo` = Kaif ka avatar. Agar Characters mein yeh dono na milen to ruk jao aur Kaif ko batao.
5. K clips mein Kaif ka chehra `me_photo` se milao. Alag shakal, alag baal, alag kapde, ya galat line boli ho to Kaif ko batao, wahi prompt dobara chalao.
6. Split clips (K2, K4, K5, K6, K7, K9) mein chehra frame ke upar wale hisse mein hona chahiye. Neeche ho to dobara.
7. Har clip download karo, naam neeche diye "File" jaisa. Kaif unhe project ke `raw-clips/` folder mein rakhega.
8. Ek ek clip banao, order mein: K1 pehle. K1 ke baad ruk ke Kaif se poochho ki awaaz aur Hindi line sahi hai ya nahi, phir baaki.
9. Clip mein koi likha hua text, logo, ya doosra insaan nahi.
