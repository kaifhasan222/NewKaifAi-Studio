# Motion styles

Source: [Nafay 3D Style Library](https://nafay3d.com). Public style names, checked 30 Oct 2026. Naye styles site par har hafte aa sakte hain. Video se pehle site ek baar khol ke list confirm karo.

Look copy karo. Unka prompt text, footage, music, voice, ya logo copy mat karo. Animation hum HyperFrames ya `build_video.py` se original banate hain. Site par email daal ke prompt unlock mat karo. Kaif khud login karta hai.

## Episode se pehle poochho

Kaif ko yeh list dikhao aur ruk jao:

1. Creator Motion Graphics
2. Chalk Talk
3. Clean Tech
4. Software Walkthrough
5. Data Story
6. Warm Canvas
7. Pop Info

- Kaif ek naam bole (jaise "Pop Info") to wahi style use karo.
- Kaif bole "jo achha ho", "best style", ya "tum decide karo" to neeche ki table se ek style chuno, naam aur wajah likho, phir banao. Dobara mat rukna.
- Kaif reference video de to pehle `prompts/reference-style-workflow.md`. Library tab use karo jab reference na ho.

## Styles

| # | Style | Family | Kab use karo | Look |
|---|---|---|---|---|
| 1 | Creator Motion Graphics | Kinetic type | Opinion, hook-heavy, tez edit | Bade condensed words, ek yellow accent word, highlighter, hand-drawn circle aur arrow |
| 2 | Chalk Talk | Hand-drawn | Concept step by step sikhana | Green board, chalk strokes, colored chalk, dust |
| 3 | Clean Tech | Screen and UI | Tool ya product, calm explainer | Off-white, dot grid, white cards, ek blue accent |
| 4 | Software Walkthrough | Screen and UI | App ka demo, clicks | App window, cursor, click ripple, zoom on the action |
| 5 | Data Story | Data | Numbers, comparison, charts | Dark ink, ek warm accent, numbers mono, chart khud draw ho |
| 6 | Warm Canvas | Talking head | Kaif camera par ho | Footage plus warm off-white cards |
| 7 | Pop Info | Illustrated | Ek idea, facts, cartoon explainer | Flat vector scene, chhota character, teal thought bubble |

## Best-style pick

| Topic jaisa ho | Style |
|---|---|
| Ek fact ya news, bina chehre | Pop Info |
| Raya ya tez hook | Creator Motion Graphics |
| Kaise kaam karta hai, steps | Chalk Talk |
| Ek AI tool, shaant | Clean Tech |
| Screen par click-by-click | Software Walkthrough |
| Percentage, paisa, chart | Data Story |
| Kaif khud bol raha ho camera par | Warm Canvas |
