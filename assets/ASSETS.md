# Free assets: sources aur rules

**Rule:** sirf woh asset jiska licence commercial use (monetized YouTube/Reels) allow kare. Har asset ka source aur licence `assets/LICENSES.md` mein likho. Daalne se pehle site par licence khud check karo, kyunki terms badalte rehte hain.

- **SFX:** Freesound (sirf CC0 filter), Pixabay Sound Effects, Mixkit

- **Fonts:** Google Fonts (open licence)
